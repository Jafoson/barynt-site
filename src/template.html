        Self-hosting

        Running in the time it takes to make coffee.

        One line on a Linux server. No clone, no build step, no secrets to make up yourself.

        1. Run the installerIt checks for Docker and installs it if you agree, then writes a .env with generated secrets.
        2. Tell it your domainPoint the domain and files. for uploads at the server. Caddy gets the certificates by itself.
        3. Open it and sign upThe first account becomes the administrator. barynt handles upgrades and backups from then on.
        Linux amd64 · arm64Docker installed if missingPorts 80 & 443
